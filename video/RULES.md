# Video rules: Nimiq Mini Apps Competition, Cycle III

Sources read on 2026-11-10:
- Rules: https://miniappscompetition.com/rules
- Scoring: https://miniappscompetition.com/scoring
- Cycle 3 announcement: https://www.nimiq.com/blog/mini-apps-competition-cycle-3-announcement/

| Rule | Quote / source | Class |
| --- | --- | --- |
| Video optional | "A demo video or walkthrough is optional but encouraged, and helps the Community Council evaluate your Mini App." (rules) | soft |
| Video link must be public | Submission bot checks the demo video is a public YouTube, Loom, Vimeo or X link (submission PRs on github.com/nimiq/miniappscompetition-submissions) | hard (for the link) |
| Length | No length limit stated | soft: target ~2:00 |
| No prototypes or mockups | "No prototypes or mockups." (rules) | hard: the film shows the real app only, labelled where it is the demo chama or a local test run |
| Description | Written description max 250 words (rules) | hard (form, not film) |
| Must support USDT or NIM through Nimiq Pay | rules | shown in the film: NIM/USDT → Lightning via `payLightningInvoice` |
| Scoring | 45 functionality/reliability/usefulness, 25 Nimiq Pay + Nimiq integration, 15 real usage, 10 design/UX, 5 builder promotion (scoring) | the film should show: core feature end to end, error handling, who it is for within seconds, Nimiq integration by name |

No rule on TTS, music, speed-ups or language. Stricter reading applied anyway: no speed-ups without a label; every
take labelled (demo chama, local test with mock partner, live site).
